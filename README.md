# File Sorter Script

## Overview
The File Sorter is a Python script designed to organize files within a directory. It automatically categorizes files into folders based on their type (Documents, Images, Videos, Audio, Archives), lists all files in a directory, and removes duplicate files.

## Requirements
- Python 3.6 or higher
- Operating System: Windows, macOS, or Linux

## Setup
1. Ensure Python 3.6 or higher is installed on your system.
2. Download the `file_sorter.py` script to your preferred directory.

## Usage
Run the script from the command line:

```bash
python file_sorter.py
